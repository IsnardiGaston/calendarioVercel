# Eventos - Mes del Trabajador 2026

## Estructura de un Evento

```typescript
interface Event {
  id: number
  day: number                              // Día del mes (1-31)
  date: string                             // Fecha en formato ISO (YYYY-MM-DD)
  title: string                            // Nombre del evento
  cat: 'cuerpo' | 'mente' | 'comunidad'   // Categoría
  time: string                             // Hora del evento
  desc: string                             // Descripción
  sedes: string[]                          // Ubicaciones donde se realiza
}
```
